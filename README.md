# Dol-BlogArchive
<hr>
Currently divided into only two sections: <i>All Comments / Bailey-Related</i>. Other characters can be found using keyword searches and filters. AI was used to assist with the scripts and some of the code.

Only the English version is available for now. The Chinese translation is still in progress, using AI translation followed by human review and editing. This may take some time, so please bear with me.

Comments are archived up to `27 October 2026 (v0.5.13)`. Some comments do not yet have author replies, as they were posted relatively recently. This is primarily a personal archive for easier searching and preserving comments from earlier versions. Some improvements to the mechanics and user experience are planned, **but there will be no further content updates.**

`ch`: Chinese translation / `en`: original English version. Choose whichever file you prefer.

## Content and Usage

**ViewerFile:** Download and extract the files, then import the corresponding `.jsonl` file to browse the archive.

**ViewerInserted:** Ready to browse immediately, but note that the file is considerably larger.
